# 佐证材料认定规则

## 一、什么算数

| 凭证类型 | 说明 | 典型形态 |
|---|---|---|
| 获奖证书 / 奖状 / 奖牌 | 由主办单位或组委会颁发，有获奖人、赛项、等级、颁证单位、日期 | 扫描件、翻拍件 |
| 红头公文 | 有发文机关标志（红头）、文号、公章或成文日期 | 通报、通知、批复、立项名单、获奖名单 |
| 盖章立项 / 结题件 | 项目计划任务书、立项通知、验收表、结题证书 | 封面 + 签署盖章页 |
| 共建协议 / 成立文件 | 联合体、产业学院等，需各方盖章 | 协议签署页、成立批复 |
| 官方公示名单 | 有发布单位与日期，能查到本人/本校条目 | 公示原文（非网页截图）、拟获奖名单 |
| **过程性材料** | 能证明"怎么做的""有没有落地" | 工作方案、筹备分工、任务通知书、竞赛指南、日程安排、抽签编号表、改期通知、集训/备赛计划、会议纪要、走访记录、预算表、赛场执行记录、开题/中期/结题材料、课程标准、数字化资源截图、教研记录 |

**"盖章原件的翻拍件"优于"电子版截图"**。能拿到纸质件就拍纸质件：正着拍、别切边、含完整边框。

## 二、什么不算数

| 不算数 | 原因 |
|---|---|
| 竞赛项目跟踪表、获奖统计 Excel、项目台账 | 内部台账，无授予单位，只能用来找线索 |
| 周报、新闻稿、公众号文章 | 宣传材料 |
| 无红头无章的网页导出 docx | 无法证明发文主体 |
| 培训结业证书 | 证明"参加过培训"，不证明"获奖" |
| 参赛报名通知 / 选拔通知 | 证明"参赛"，不证明"承办"或"获奖"；但若**附件里载明赛场设在本校**，该附件可证承办 |
| 工作方案的草稿（带"X月X日"占位） | 未定稿 |
| 其他部门的项目 | 归口不符，评审会追问 |

**注意**：上表排除的是"自说自话、无责任主体"的汇总台账，以及"拿相近文件顶替结果指标"。同一文件用于证明组织、参与、推进过程时，按第一节的过程件认定。

## 三、年份口径

- **获奖类**：优先任务当年。当年无凭证时按下面"缺口兜底顺序"降级，描述必须写实注明实际年份。
- **立项 / 批复类**：可比任务年度早一年。2025 年度任务用 2024 年立项名单是正常的（立项在前、建设在后）。
- **承办类**：以实际承办年份为准；任务年度与材料年份不一致时，抬头可跟材料年份走，但描述要写实际年份，别写无依据的"下一年度继续承办"。
- **抬头年度**：默认跟任务年度走，与合并总表对齐。若整份材料全是上一年度凭证、用户明确要求按材料年份写，才改成材料年份，并在描述里说明。

同一批成果不要同时充两个年度同一指标。指标文字是"累计超过 10 项"时可以复用，但**后一年度的描述必须改成"截至 YYYY 年累计…"**，不能仍写上一年度；若是"本年度获奖 10 项"，不能复用。

## 三之二、缺口兜底顺序（缺口取证次序）

指标严丝合缝凑不齐时，按下列顺序退让，**每一级都要在描述里写实，不能含糊成"完成"**：

1. **同赛事降级**：一等奖没有 → 用二等奖、三等奖（数量够即可）。
2. **换主办口径**：教育口没有 → 用省级技能大赛、行业协会赛。
3. **跨年度**：任务当年没有 → 上一年 → 上两年（抬头年度跟材料年份走，描述注明实际年份）。
4. **换相近赛项**：指定赛项没有 → 同专业方向的其他赛项。

材料册不留空时，按兜底顺序用相近凭证补齐，确实无解时才在交付说明里写清缺什么、找谁要。降级取证仍要遵守"描述写实"：任务"省级教学能力比赛一等奖"用"竞赛优秀指导教师证书"时，描述写"教学能力经省级竞赛检验"，不写"获一等奖"。

## 三之三、奖项归属怎么判（最容易出错）

1. **以归口部门自己的统计表为准**，不要用学校总表的"承办部门"去覆盖它——两表冲突时听归口部门的。
2. 统计表里"承办部门"列写的是哪个学院，就按哪个算；合并单元格的空白行继承上一行。
3. 赛项没进统计表时，**看一等奖第一指导教师所属系部**：第一指导教师是本单位的就是本单位的，第二位不算数。实践中可按此口径把同一赛项里归属成立的若干项计入本单位。
4. 同一赛项常有多支队伍、多个奖项，只取归属成立的那几行，红框也要只框这几行。

## 三之四、凭证规范细则

- **红头或公章二选一即可**，不必两者兼有。
- **竞赛类附件不能只有获奖名单截图**，须有文件首页（能看出是什么事）+ 公章；与本院无关的整页可省略。
- **排序**：有公章/红头的材料在前、无章的在后；主办单位"总"的公文在前、系部内部材料在后。
- **客观例外**：有些官方公示名单本身无红头无公章。这类只能呈现名单并争取主管部门盖章证明，属已知缺件，不算违规。
- **只考规划的任务**（如产教联合体建设规划）：无章校内文件即达标，不算缺件；但描述若承诺"成立工作小组"仍须有成立文件。
- **红章判定别只靠脚本**：红色像素阈值会漏判褪色扫描章，逐张目检确认。曾有一份部门盖章的工作联系单被脚本误判为"无章弱证据"而长期漏用。
- **过程件也要讲凭证**：`.doc` 纯文字渲染件无章时，靠"通知 → 工作方案 → 筹备分工"链兜底；能拿到盖章扫描件更好。

## 四、任务类型 → 该找谁要什么

| 任务关键词 | 结果凭证 | 过程 / 效果凭证 | 通常在哪 |
|---|---|---|---|
| 精品课程 / 课程建设 | 立项名单、立项通知、公示 | 课程整体设计、课程标准、数字化资源（平台截图）、考核方案、教研活动记录、验收 | 科研处、教务处、课程负责人 |
| 学生竞赛获奖 | 获奖证书、主办单位通报 | 选拔通知、集训计划、报名表、训练记录、作品说明 | 竞赛归口部门 |
| 承办竞赛 | 主办单位竞赛通知、赛场安排 | 工作方案、筹备分工、任务通知书、竞赛指南、日程、抽签表、改期通知、预算表 | 竞赛归口部门 |
| 教学能力比赛 | 省级教育主管部门获奖文件、证书 | 参赛/教学设计材料 | 教务处 |
| 科研项目 | 计划任务书（封面 + 盖章页） | 开题、中期检查、试验记录、结题验收、技术报告、论文/专利/应用证明 | 项目负责人 |
| 产教联合体 / 产业学院 | 成立文件、共建协议签署页、建设规划 | 工作专班名单、动员会纪要、走访洽谈记录、意向书、阶段台账、挂牌照片 | 项目牵头人 |
| 师资 / 团队 | 认定文件、聘书、立项通知 | 培养过程、考核记录 | 人事处、教务处 |

**佐证负责人 ≠ 领办人**。总表里按"佐证负责人"列筛任务（"佐证负责人"列）；凭证往往要向领办人索取。任务编号在多个专业群间复用，须"专业群 + 编号"联合定位。

## 五、材料构成判据：结果 / 过程 / 效果

| 判据 | 达标条件 | 常见不达标情形 |
|---|---|---|
| 结果 + 过程 | 承办/建设/研究/课程类有成组过程件，且不靠内部台账充数 | 整册只有证书 + 获奖通报 |
| 制度 + 执行 | 制度类任务有制度文本 + 执行记录（发文、宣贯、验收记录） | 只放一份管理办法 |
| 方案 + 过程/效果 | 方案配筹备分工、日程、纪要或效果材料 | 两份都是"规划/方案"，零过程零效果 |
| 图片大小一致对齐 | 宽 8cm、同行等高、居中 | 同行 11.3cm 竖版 + 5.6cm 横版并排 |
| 佐证均以图片形式 | 每个材料 ≥1 图、无纯文字材料、无空表格、无占位符 | 只有文字描述或空清单行 |

**达标样例**：承办类任务宜以主办单位通知、承办工作方案、筹备分工、任务书、日程安排等过程件为主，形成"通知 → 方案 → 执行"链，不必堆获奖结果图。结果件须红头或公章；过程件按责任主体、时间与正式版式认定，无章时靠成组链条佐证。

## 六、内容写作口径（面向评审，不做内部归口说明）

1. **不写"指导教师…均为某二级学院教师"这类归属声明**——内部归口审核才需要，评审只看成果。
2. **不写"（获奖学生X，指导教师Y、Z）"式括注**；清单/材料标题不堆人名。单个获奖人 + 名次属成绩说明，可留。
3. **例外保留**：学校全称、"XX职业技术学院赛场""协办单位含…""竞赛地点：…""赛项在我院举办""集训阶段设在我院"——这些能体现学校主体，必须留。
4. 删归属声明后描述字数不够 100 时，把开头"学院"改成学校全称，既体现主体又补字数。
5. **数量词与任务标题一致**（标题"2个"vs描述"3项"必被问）；已确认的扩量口径不要擅改，但要列为交付风险。
6. **描述不承诺材料里没有的事**；若已承诺，要么索取材料，要么改写描述，二选一。
7. 清单名称与对应材料标题核心文字一致（括注详略可不同）。

## 七、常见退回原因

1. 凭证与任务指标数量不符（写"2 个一等奖"，只放了 1 张；或标题 2 个、描述 3 项）
2. 奖项等级写错（把二等奖写成三等奖，或把"团体二等"算成"个人二等"）
3. 材料名称笼统（"相关证书"），评审无法快速定位
4. 清单条数与材料个数不一致，或清单与材料标题不对应
5. 描述里写"获…/完成…"但材料支撑不了，属于虚报
6. 只有结果没有过程
7. 方案/制度孤立，没有执行或效果材料
8. 图片过小、关键信息看不清（低于 8cm 宽基本不可读）；同行图片一大一小
9. 关键行没有标注，评审要在整页名单里自己找
10. 整页与本院无关的内容未省略
11. 佐证不是图片形式，或残留模板占位文字/提示色

## 八、归档建议

```
双高/<姓名>-佐证材料/
├── 1/            已完成（有凭证）
├── 0/            未完成（空框架，含抬头/标题/描述/空清单）
└── _归档/        作废版本，不删除，便于回溯
```

文件名统一 `佐证材料-<专业群>-任务<编号>.docx`，上报时按任务号一找就着。旧版本一律先进 `~/.Trash`（带时间戳与改动标记）再放入新版，不直接覆盖。
