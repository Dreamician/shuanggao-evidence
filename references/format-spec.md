# 母版格式实测参数

以 `佐证材料-XXX专业群-任务模板.docx`（空白母版）与 `范本-佐证材料-…-任务示例.docx`（已填范本）实测为准。所有数值单位为 OOXML 原始单位。

## 页面

```xml
<w:pgSz w:w="11906" w:h="16838"/>                      <!-- A4 -->
<w:pgMar w:top="1440" w:right="1080" w:bottom="1440" w:left="1080"
         w:header="851" w:footer="992" w:gutter="0"/>  <!-- 上下 2.54cm / 左右 1.9cm / 页脚 1.75cm -->
```

版心 17.17 × 24.62cm。页脚内有文本框 `— PAGE —` 域，不要动。母版页脚有 2 个 `PAGE \* MERGEFORMAT` 域 / 2 个文本框，成品清理成 1 个也不影响显示。

## 文档块顺序（顶层）

```
段：XXX专业群
段：年度任务佐证材料
段：任务模板 XXXX（三号、仿宋、加粗、单倍行距）        ← pStyle=3（heading 1）
段：写一段话描述，100-150字。具体佐证材料如下（四号、仿宋、单倍行距）：
段：佐证材料列表
表：清单表（4 行 × 2 列）
段：材料一：XXXX（三号、仿宋、加粗、单倍行距）          ← pStyle=4（heading 2）
表：材料一表（2 行 × 2 列，首行带提示文字，次行合并）
段：材料二：                                          ← pStyle=4
表：材料二表（1 行 × 2 列）
段：材料三：                                          ← pStyle=4
表：材料三表（1 行 × 2 列）
段：（空段）
<w:sectPr>
```

**注意**：模板里材料标题与它后面的表之间可能夹 `<w:bookmarkEnd>`；材料三标题段内还带 `<w:bookmarkStart>/<w:bookmarkEnd>`。复制材料块时必须先剥掉所有书签标记，否则书签 id 重复。

## 样式与字体

| styleId | 名称 | 字号 | 加粗 |
|---|---|---|---|
| 3 | heading 1 | `<w:sz w:val="32"/>` = 16pt（三号） | 是 |
| 4 | heading 2 | `<w:sz w:val="30"/>` = **15pt** → 需改为 32 | 是 |

材料二、材料三标题段内还有显式 `<w:sz w:val="30"/>`，改样式的同时要改段内。材料一标题段内没有显式字号（继承样式），所以**两处都要改**。

**字体统一**：中文 `w:eastAsia="仿宋"`，西文 `w:ascii / w:hAnsi / w:cs="Times New Roman"`。做法：正则替换 `document.xml` 中所有 `<w:rFonts .../>`，把 ascii/hAnsi/cs 的"仿宋"改成 Times New Roman，并补 `w:eastAsia="仿宋"`。母版 Normal 样式本身即混用，以 Normal 与 GB/T 9704 为准。`"佐证材料列表"` 是黑体 12pt（`w:sz=24`），不要动。

`styles.xml` 里可能残留一个未被任何段落引用的死样式 `font41`（全"仿宋"），`docDefaults` 为宋体；可见正文 run 都显式带 `eastAsia=仿宋`，不影响交付。

## 清单表

```xml
<w:tblW w:w="4982" w:type="pct"/>   <!-- pct 单位是 1/50 %，即 99.64% -->
<w:gridCol w:w="..." />×2           <!-- 实占序号约 8.7%，名称约 91.3% -->
<w:trHeight w:val="482" w:hRule="atLeast"/>  <!-- 0.85cm -->
```

- 表头：`序号` / `佐证材料名称（五号、仿宋、加粗、单倍行距；表格高度0.85厘米）` → 后者要改成 `佐证材料名称`
- 数据行：`1` / `XXXX（五号、仿宋、单倍行距）`；数据行数应与材料数一致，序号列逐行填 1…N
- 清单表行高 0.85cm = 482 twips（模板实测）；0.94cm（=533 twips）系误传，模板与成品均无此值。

**`trHeight` 假阳性坑**：Word 会把行属性拆成两处，不要只看第一个 `w:trPr` 就下"缺行高"结论：

```xml
<w:tblPrEx>...<w:trPr><w:cantSplit/></w:trPr>...</w:tblPrEx>   <!-- 第一处 -->
<w:tr><w:trPr><w:trHeight w:val="482" w:hRule="atLeast"/><w:jc w:val="center"/></w:trPr>...
```

任务B / 任务C / 任务I 就是这样，曾被子代理误报"缺 482"，复核后撤回。

## 材料表

```xml
<w:tblW w:w="4994" w:type="pct"/>   <!-- 材料一；材料二/三为 5000 -->
<w:gridCol w:w="4975"/>×2            <!-- 材料一 -->
<w:tcBorders> 全部 nil </w:tcBorders>  <!-- 单元格无边框，图片周围不会出现空框 -->
```

- 一页两张 8cm 图：1 行 × 2 列，共 16cm（版心宽约 17.2cm，余约 1.2cm）。
- 奇数张：末行两格合并（`<w:gridSpan w:val="2"/>`，`tcW` 由 2500 pct 改为 5000 pct），图片居中。
- 材料一的表在母版里带提示文字（`竖图宽度8厘米` / `图片相关文字部分用红框框住` / `横图宽度8厘米`）和第二行合并，**建议统一用材料三那张干净的表做原型重建**。
- 材料表**不要设固定 `trHeight`**，否则大图会被挤到下一页。
- 材料之间**不加强制分页**（模板 `pageBreakBefore=0`），只保留模板自带的 `keepNext`。

## 图片

- 显示宽度 8cm = `cx="2880000"` EMU；`cx=2876550`（7.99cm）也可接受。8cm 宽对应 605px 位图，约 192dpi。
- 图片段落必须 `<w:jc w:val="center"/>`（`jc` 在 `pPr` 中位于 `ind` 之后、`rPr` 之前）。
- 图片所在表格行必须带 `cantSplit`（`<w:cantSplit/>` 或 `<w:cantSplit w:val="1"/>` 均为合法 CT_OnOff）。
- **显示宽高比必须等于原图宽高比**（偏差 >2% 即变形，`audit.py` 逐张点名）。
- **同一行两图必须等高**（图片大小一致对齐）。竖版 A4 画框图 605×856 → 11.30cm；横版证书 605×423 → 5.58cm；两者并排差 5.7cm 属硬伤。
  - 正确修法：把矮图**垂直居中留白**成 605×856 白色画布（内容不缩放、不拉伸），并把对应 `wp:extent cy` 改成与并排图相同的 EMU 值。版面总高不变、零掉图风险。
  - **禁止**直接把矮图的 `wp:extent cy` 拉到 11.30cm（会触发变形检查、证书被纵向拉长）。
  - **禁止**把横版名单裁块（605×169）套 A4 画框：会留 9cm 白边或把字拉长 5 倍。左右裁块相差 2–3px（0.026cm）属不可辨微差，不必修。
  - 单图独占一行（合并居中）不存在同行比较，允许与别的材料不同高；模板只约束"竖图/横图宽度 8cm"。
- 多页公文统一 A4 画框 605×856：两行 22.60 + 标题 1.30 = 23.90cm，版心 24.62cm，留 0.72cm。若两行图合计达 24.14/24.32cm，加标题即超版心，Word 会掉图。

## 模板等价性判定

收到"新模板"时先逐 part 比对，不要盲目按新模板返工。新收到的空模板 / 已填范本 / 旧母版结论：**格式等价**，12 个 part（`styles.xml`、`footer1.xml`、`footnotes.xml`、`endnotes.xml`、`theme1.xml`、rels、Content_Types、customXml）字节级相同；差异仅：

1. 书签 `_Toc…` id↔name 映射重排、`_GoBack` 位置移动（Word 重新保存重编号）
2. `<w:tblPrEx>` 冗余属性块位置不同，边框值一致
3. `w:gridCol` 绝对 twips 缩放（清单 `848/8853 → 868/9058`），但 `tblW/tcW` 均为 pct，`848:8853 = 868:9058 = 8.74%:91.26%`，版式无差异
4. 元数据 docProps、fontTable、settings 的小差异

**结论**：全部段落文字、`w:sz`(44/32/28/24/21/30)、`w:b`、`w:spacing line=240 auto`、`w:ind firstLine=560`、`w:jc`、`rFonts`、`trHeight=482`、表格行列结构逐项相同 → 成品无需重建。

## 范本对照（任务示例）

- 两张图各 **8.00 × 10.81cm** 并排，共 16cm；显示高差 1270 EMU（0.003cm）属模板级微差
- 图为盖章原件的翻拍件，关键栏用红框圈出

## 编辑器保存会丢属性（重要）

在 WPS / 腾讯文档预览 / editor_sdk 里打开并保存后，表格行属性会被重写：

- 9 个图片行丢掉 `cantSplit`（图片被页面切断）
- 8 个 `cantSplit` 变成 `<w:cantSplit w:val="1"/>` 变体

所以：**属性修复必须放在最后一次编辑器保存之后**，用直接改写 OOXML 的方式做；改完提醒用户别再在编辑器里保存，或保存后重跑修复。`audit.py` 已兼容 `w:val="1"` 变体。

## 复核检查项速查

| 层 | 检查项 |
|---|---|
| 文字 | 抬头年度、任务标题与总表原文、描述 100–150 字、清单行数=材料数、序号连续、清单↔标题对应、无占位残留、无非黑文字 |
| 字体 | eastAsia=仿宋 / ascii·hAnsi·cs=TNR、heading2=32(16pt)、"佐证材料列表"黑体 12pt |
| 页面 | pgMar 抽查 bottom/left、页脚 PAGE 域 |
| 表格 | 清单 trHeight=482（注意 tblPrEx 拆分）、所有行 cantSplit、材料表无固定行高 |
| 图片 | 数量=媒体数、宽 8cm、居中、显示比=原图比、**同行等高**、无空白/黑边/裁切过度 |
| 内容 | 过程性材料、方案/制度配执行、无内部归属声明、数量词一致、描述不虚报、含学校主体表述 |
